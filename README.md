# Трекер сна

Приложение для iPhone: оценка сна, умный будильник, учёт храпа, данные с Xiaomi Smart Band 9, запись в «Здоровье» и виджеты.
Написано на React Native (Expo SDK 58), виджеты — на Swift. Собирается в облаке (GitHub Actions или EAS), Mac не нужен.

## Что умеет

| Функция | Как работает |
| --- | --- |
| Сон с браслета (способ 1) | Mi Fitness выгружает сон и пульс в Apple «Здоровье», приложение читает их оттуда. Точные фазы, но данные появляются утром. |
| Браслет напрямую (способ 2) | Bluetooth, стандартный профиль Heart Rate: пульс в реальном времени, пока идёт ночь. Нужна «Трансляция пульса» на браслете. |
| Умный будильник | В окне перед назначенным временем будит, когда сон лёгкий: по движениям (акселерометр телефона на матрасе), росту пульса и звукам. В назначенное время будит всегда. |
| Храп (по желанию) | Микрофон iPhone, анализ громкости: серия ритмичных звуков = храп. Звук не сохраняется. |
| Оценка сна 0–100 | Длительность 40, эффективность 20, глубокий сон 15, REM 15, непрерывность 10, до −10 за храп. |
| «Здоровье» | Читает сон и пульс; записывает ночи, отслеженные самим приложением. |
| Виджеты | Малый, средний и два для экрана блокировки: оценка, длительность, фазы, время будильника. |

## Ограничения, о которых надо знать

- **Сохранённый браслетом сон по Bluetooth не скачивается.** У Band 9 закрытый протокол с шифрованием; он не реализован. Точные фазы приходят только через Mi Fitness → «Здоровье».
- **«Трансляция пульса» на Band 9 не проверена.** Если такого пункта на вашем браслете нет или он выключается сам, способ 2 работать не будет — останутся способ 1 и трекинг телефоном.
- **Умный будильник не видит фазы браслета в реальном времени** — браслет их не отдаёт. Момент пробуждения выбирается по движениям, пульсу и звукам.
- **Фазы собственного трекинга — приближение**, а не медицинское измерение. Без пульса различаются только сон и пробуждения.
- Чтобы ночью приложение не засыпало, оно либо пишет звук (если включён храп), либо проигрывает тишину. Закрывать его смахиванием нельзя. На случай, если iOS всё же выгрузит приложение, на назначенное время ставится уведомление со звуком (до 30 секунд).
- Нативная часть (HealthKit, Bluetooth, фоновый звук, виджеты) **не запускалась на iPhone** — на Windows её собрать нельзя, сборка идёт в облаке. Проверены типы, логика (тесты) и интерфейс в браузере.

## Установка на iPhone бесплатно (GitHub Actions + Sideloadly)

Подходит для бесплатного Apple ID и Windows. Приложение работает 7 дней, потом его нужно установить заново тем же способом (данные сохраняются).

1. Выложите проект в репозиторий на GitHub. В публичном репозитории сборки бесплатны; в приватном одна сборка съедает заметную часть месячного лимита (минуты Mac считаются в 10-кратном размере).
2. На GitHub откройте вкладку Actions → «iOS (без подписи)» → Run workflow. Сборка идёт примерно 20–40 минут.
3. Когда она закончится, откройте её страницу и скачайте внизу артефакт `SleepTracker-ipa`. Распакуйте архив — внутри `SleepTracker.ipa`.
4. Установите на компьютер iTunes и iCloud с сайта Apple (не из Microsoft Store) и Sideloadly с sideloadly.io.
5. Подключите iPhone кабелем, откройте Sideloadly, перетащите в него `SleepTracker.ipa`, введите Apple ID и нажмите Start. Sideloadly передаёт Apple ID и пароль в Apple для подписи; при желании заведите для этого отдельный Apple ID.
6. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID. Затем Настройки → Конфиденциальность и безопасность → Режим разработчика → включить.

Что может не заработать с бесплатным Apple ID (на телефоне не проверено):

- **«Здоровье».** Если Sideloadly не сможет выдать право HealthKit, приложение покажет сообщение об ошибке при включении «Читать сон из "Здоровья"». Остальное продолжит работать.
- **Виджет.** Ему нужна общая группа данных с приложением; при переподписи её идентификатор может измениться, и виджет покажет «Нет данных о сне».
- **Срочные уведомления.** Запасной будильник придёт обычным уведомлением, режим «Сон» может его заглушить. Основной будильник звучит из самого приложения и от этого не зависит.

Сама сборка в GitHub Actions ещё ни разу не запускалась. Если она упадёт, пришлите текст ошибки из журнала.

## Сборка с платным аккаунтом (EAS)

С платным аккаунтом Apple Developer (99 $ в год) нет ограничения в 7 дней, а HealthKit, виджет и срочные уведомления подписываются штатно.

1. Замените заглушки на свои значения:
   - `app.json`: `ios.bundleIdentifier`, `ios.appleTeamId` (Team ID из developer.apple.com → Membership), App Group в `ios.entitlements`;
   - `src/config.ts`: `APP_GROUP` и `BUNDLE_ID`;
   - `targets/widget/SleepWidget.swift`: константа `appGroup`.

   App Group должен быть одинаковым во всех трёх местах.

2. Войдите в Expo и привяжите проект:

```bash
npx eas-cli@latest login
```

```bash
npx eas-cli@latest init
```

3. Зарегистрируйте iPhone (откроется ссылка, которую нужно открыть на телефоне):

```bash
npx eas-cli@latest device:create
```

4. Соберите приложение. EAS сам создаст сертификаты и профили, в том числе для виджета:

```bash
npx eas-cli@latest build --platform ios --profile preview
```

5. Откройте ссылку из результата сборки на iPhone и установите приложение. В iOS включите Настройки → Конфиденциальность и безопасность → Режим разработчика.

Профиль `development` собирает версию с клиентом разработки: код можно менять без пересборки, запуская `npx expo start` на компьютере в той же сети Wi‑Fi.

## Настройка после установки

1. **Mi Fitness → «Здоровье».** В Mi Fitness: Профиль → Настройки → Подключённые приложения → Apple Здоровье, включить сон и пульс. В приложении: Настройки → «Читать сон из "Здоровья"».
2. **Bluetooth (по желанию).** На браслете включить трансляцию пульса, в приложении: Настройки → «Найти браслет».
3. **Храп (по желанию).** Настройки → «Храп».
4. **Виджет.** Долгое нажатие на экран «Домой» → «+» → «Трекер сна».

## Структура

- `src/lib` — чистая логика: оценка (`score.ts`), фазы (`staging.ts`), храп (`snore.ts`), будильник (`smartAlarm.ts`), сборка ночи (`night.ts`).
- `src/services` — «Здоровье» (`health.ts`), Bluetooth (`band.ts`), ночной трекинг (`tracker.ts`), виджет (`widget.ts`), хранилище (`storage.ts`).
- `src/screens`, `src/ui` — экраны и компоненты.
- `targets/widget` — виджет на SwiftUI.
- `scripts/test-logic.ts` — тесты логики, `scripts/make-sounds.mjs` — генерация звуков.

Приложение не ставит диагнозов и не заменяет врача.
